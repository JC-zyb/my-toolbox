# 个人工具箱

Rust / Tauri 2 / React / TypeScript 的本地个人工作台。默认七天的 Agents 用量总览，配套浅色和深色主题。

## 启动

需要 Node.js 20.19+、Rust 和 Windows Tauri 构建环境（MSVC Build Tools 与 WebView2）。

```text
npm ci
npm run desktop
```

`npm run dev` 只打开浏览器 UI，明确显示桌面能力不可用，不模拟本机用量或系统操作。`npm run desktop` 启动开发服务器和开发窗口。

可直接启动的桌面程序使用 `npm run build:desktop` 构建，前端文件嵌入可执行文件，输出为 `src-tauri/target/debug/my-toolbox.exe`，无需运行 Vite。普通 `cargo build` 生成的开发程序仍依赖 `127.0.0.1:1420`，不能作为独立程序交付，也会覆盖同路径文件。安装包可使用 `npm run tauri -- build` 构建。

## 已实现

- 用量总览：时间/来源筛选、输入输出与缓存、来源成本、趋势表格与 CSV、Agent 排名、模型分布、最近会话。
- Agents / 数据源：目录登记、独立暂停、来源状态与解析诊断、启动客户端、打开目录。
- 会话：搜索、模型筛选、分页、CSV、元数据与用量详情。
- Skills：中央库卡片浏览、完整详情与 Agent 即时启停、批量操作、Agent 独有技能导入、新建/编辑、本地与 GitHub 导入、全局/项目分发预览、差异与冲突处理、迁移备份、更新提示与导出。
- Agent 资讯：Agent 生态与中文媒体订阅、中文翻译与双语阅读、工具内内容预览、领域/分类/来源/时间/搜索筛选、自动更新、自定义订阅和离线缓存。
- 工具：快速入口登记、批量改名预览/冲突检查/确认执行、脚本登记/确认执行/超时/输出。
- 本地工具：本机扫描、多份安装与来源识别、GitHub 资料搜索和补全、管理器更新查询、安装升级卸载预览、多版本默认值和项目版本固定、后台任务与日志。
- 系统：本地持久化设置、自动采集、命令面板、键盘导航、托盘和单实例。

## 数据边界

原始客户端文件只读。Codex 读取 `.codex/sessions` 与 `archived_sessions` 的 JSONL（含 `.jsonl.zst` / `.jsonl.zstd` 压缩日志）；Claude Code 读取 `.claude/projects`；DSH 读取 `.dsh/storages/cost-meter/ledger.json` 的 version 1 账本。仅保存会话元数据与用量，不保存对话、工具输出或凭据。工具箱缓存位于 Tauri 应用本地数据目录（可在设置中打开），SQLite 缓存按文件修改信息更新，失败保留上次成功数据并暴露诊断。已采集文件移除或移出扫描目录后，其缓存历史仍计入统计；尚未采集且已删除的日志无法恢复，同一账本文件内部裁剪的旧记录不保证保留。总览默认最近七天，查看历史总量需选择“全部”。

输入包括缓存读取/创建，推理若属于输出不再次累加。金额目前只汇总来源成本（USD）；未提供价格的模型显示未知，不推算订阅账单。Codex 无法从用量事件确定请求数，调用显示未知；Claude 按消息身份去重，DSH 使用来源调用数。日界限采用 Asia/Shanghai，DSH 保留账本日期。客户端版本未自动探测，显示未读取。

批量改名只处理指定目录下的文件、不递归且不覆盖已存在目标；失败尝试回滚并报告。脚本输出最多保留标准输出和错误各 1 MiB；超时终止直接进程，脚本自行启动的子进程仍需脚本管理。脚本参数通过结构化参数传递。

## Skills 使用

在桌面版左侧打开 Skills。中央库固定为 `~/.agents/skills`；全局 Codex 直接发现中央库，`.codex/skills` 只作为兼容扫描和清理入口。Claude Code 与 DSH 分别使用 `.claude/skills` 和 `.dsh/skills` 的单技能入口。项目需要手动登记，只扫描和分发到所选工作区；项目 Codex 使用项目 `.agents/skills` 安装入口。

技能库默认显示卡片：名称、描述、来源及右下角 Claude Code、Codex、DSH 状态图标。彩色表示已启用，灰淡表示已关闭，读取失败显示未知状态；同名不同内容另标记版本冲突。点击卡片进入主内容区完整详情，可查看渲染后的 SKILL.md 正文、源码、来源和真实差异；返回保留搜索、筛选与滚动位置。勾选 Agent 立即启停，冲突、外部目录和首次导入会先显示确认。Agent 独有技能可在详情中确认来源后导入中央库并启用其他 Agent。

卡片右上角滑动开关控制当前工作空间所有可管理 Agent，半选点击后全部启用；右下角 Agent 图标可单独切换，不受 Agent 筛选改变总开关范围。左上角悬停或键盘聚焦显示更多菜单，支持方向键、Escape、编辑、导出、删除及来源查看。多选中的“全选当前结果”只选当前筛选结果并支持半选。

启停立即反馈，后台只校验当前技能及目标入口，不扫描整个库；处理中仍可点击，同一技能按顺序提交并合并各 Agent 的最后意图。成功增量与详情共享，失败只恢复本次目标的已确认状态。右下角显示操作结果，短操作不闪出处理中通知；成功约 3 秒后关闭，失败或需要确认的通知保留到关闭。返回技能库不会触发全库扫描，外部修改可用“扫描”刷新。

全局 Codex 通过 `~/.codex/config.toml` 的 `[[skills.config]]` 对实际 `SKILL.md` 路径设置 `enabled`，默认无配置视为启用；修改后重启 Codex 生效。项目 Codex 使用项目安装入口，关闭项目入口不影响全局技能。Claude Code、DSH 的关闭会备份并移走对应安装入口，中央库内容保持。多选模式一次预览并应用所选技能和 Agent 的启停；兼容入口清理放在高级操作中，与关闭技能分开。

内部统一矩阵继续合并中央库、各 Agent 独有技能和旧 `.skills-manager/skills` 中的同名记录，供卡片、筛选和预览共用状态。可筛选重复入口、冲突、Agent 独有及未安装；路径、模式和指纹在来源详情及操作预览中查看。

批量分发使用自动链接：Windows 先 junction 再 symlink，失败原因直接显示；高级设置明确允许后才可复制降级。原单技能详情的同步模式继续作为高级选项。批量冲突默认保留已有版本并跳过，可逐项改为中央版本或保留目标并导入中央。同一技能不能同时选择不同中央版本。确认后再次核对内容指纹和父目录边界，过期预览不能执行，任一运行时错误逆序恢复文件并回滚 SQLite。

高级兼容入口清理作用于所选 Agent 的安装，包括已发现的外部目录和联接，先预览完整路径和修改状态，原目标移入相邻备份，中央内容及联接源保留；本地已修改的副本默认跳过。清理全局 Codex 只移除 `.codex/skills` 的兼容入口，全局 Codex 的启停须使用详情勾选或批量启停。删除中央内容仍需在详情中单独确认名称、指纹及备份。原单技能解除分发接口继续仅处理工具管理且未被外部改变的目标。

首次访问发现 `.skills-manager/skills` 内容时显示只读迁移向导，冲突默认保留中央版本，来源独有项默认导入。确认后备份内容、校验复制、重建 Claude/DSH 旧库入口，并清理 Codex 兼容入口；迁移源保留，重复执行不覆盖已相同的内容。若整个 Agent `skills` 目录联接到旧库，迁移备份目录联接后改为普通目录和单技能入口；此时必须处理全部迁移项，避免部分迁移影响未处理内容。普通批量操作会阻止穿透整目录联接，提示先迁移。

备份位置显示在公共仓库设置与最近操作中。同一磁盘的替换使用相邻 `.toolbox-backup-*` 目录保留原版本，应用数据目录保存迁移备份及 `skills.sqlite` 元数据。运行时错误尝试回滚；进程突然退出仍可能需要人工从备份恢复。

GitHub 导入支持 HTTPS 仓库 URL 与 branch/tag/commit，浏览有效 Skill 后选择导入。Git 必须可用；网络、认证及格式错误直接显示。仓库 checkout 与来源 commit 保存在应用数据目录，更新检查只提示，不覆盖中央库。自动检查仅在 Skills 页面打开期间每小时运行。默认拒绝同名不同内容的导入与 Skill 内部链接；不会读取链接指向的库外文件。Skills 命令面板支持技能搜索、导入仓库、项目工作区与当前技能分发预览。

## 环境变量

从侧栏“系统 → 环境变量”进入，支持 Windows 桌面版的用户变量与系统变量搜索、新增、修改和确认删除。直接读取持久化注册表中的原始值，保留 `%JAVA_HOME%` 等引用及 `REG_SZ` / `REG_EXPAND_SZ` 类型；Path 可在原始值和每行一个路径之间切换，保留顺序、空条目和尾分号。空值保存为空字符串，删除使用单独确认。

变量列表突出名称与类型；Path 按原始顺序分行编号，前三项之外可展开，空条目有明确标识。可展开字符串的 `%变量名%` 引用单独高亮，普通长值支持查看完整内容；展示拆分不会改变保存值。窄窗口使用纵向布局，编辑框显示路径条目数或字符数。

系统变量按当前进程的注册表写入权限显示可编辑或只读，不自动提权；需要时关闭工具箱后以管理员身份重新启动。保存前核对原值版本，外部修改或同名变量已存在时拒绝覆盖并提示刷新。保存后广播环境变更通知，通知失败会显示“已保存，但通知未完成”；已运行的终端、开发工具和工具箱自身需要重新启动才能使用新环境。

浏览器、macOS 与 Linux 暂不支持此编辑功能。环境变量值不写入工具箱配置或日志。开发测试使用独立注册表键和隔离页面，不修改真实用户或系统环境变量。实现思路参考 [PowerToys 环境变量模块](https://github.com/microsoft/PowerToys/blob/main/doc/devdocs/modules/environmentvariables.md)，边界与取舍见[环境变量决策笔记](.agents/notes/implemented/feature/2026-10-22-environment-variables.md)。

## Agent 资讯

从侧栏“工作台 → Agent 资讯”进入。内置 32 个 RSS / Atom 来源，覆盖通用与办公 Agent、编程 Agent、Agent 框架、工作流平台、模型生态、协议及中文资讯。例如 OpenHands、OpenClaw、DeerFlow、Gemini CLI、Cline、OpenCode、CrewAI、AutoGen、Qwen-Agent、AgentScope、Dify、Coze、n8n、A2A，以及原有 Codex、Claude Code、LangGraph 等；模型消息来自 OpenAI、DeepMind、Hugging Face，中文消息来自量子位、IT之家和 InfoQ 中文。综合科技订阅按 AI / Agent 标题关键词过滤，也可收录闭源产品的媒体报道。有限来源不等于穷尽全部 Agent，来源更新时间和覆盖范围由发布者决定。

“订阅来源”支持添加公开 HTTPS RSS / Atom，或填写 GitHub 仓库首页自动转为 Releases Atom；先验证真实订阅再保存。可按领域归类、搜索来源、暂停任意来源，移除自定义来源。最多 100 个来源，偏好重启后保留。参考 [TrendRadar](https://github.com/sansan0/TrendRadar) 的 RSS 获取与失败隔离、[Horizon](https://github.com/Thysrael/Horizon) 的多源聚合，以及 [translate-tools/core](https://github.com/translate-tools/core) 的公开批量翻译请求方式，未引入独立采集服务或 LLM 调用。

桌面窗口运行时自动检查，每个来源每 30 分钟更新；切到其他页面仍继续，应用退出后停止。可关闭“自动更新”，或在“订阅来源”暂停单个来源；手动刷新只请求启用的来源。失败保留该来源已有资讯，并分别展示错误和上次成功时间。缓存和偏好保存在应用数据目录 `agent-news/news.sqlite`，每个来源最多保留 100 条，使用 ETag / Last-Modified 减少重复传输。

默认显示最近 30 天；可筛选全部时间查看旧条目和没有发布时间的条目。显示发布者提供的日期，缺少发布日期时使用其更新时间，都没有则显示未知；时间按 Asia/Shanghai 呈现。分类基于标题关键词与来源类型，只供筛选；GitHub 发布记录包含预发布版本。原始摘要取自订阅，转为纯文本呈现，不是 AI 生成摘要。

默认中文模式，当前阅读列表的外语标题与摘要按需翻译，译文标记“机器翻译”；支持原文和双语，语言偏好会保存。仅将公开资讯文本发给 Google 公共翻译接口 `translate.googleapis.com`，不需要密钥；原文模式停止新的翻译请求。该接口没有付费 Cloud Translation 的服务保证，可能限流或变更，失败会显示原因并允许手动重试，不伪造译文。译文缓存在本地，原文内容改变后失效；原生中文直接保留。搜索可匹配原文和已有译文，不会为一次搜索翻译整库。

点击资讯标题先打开工具内预览，可阅读订阅内容或网页摘录，支持中文、双语和原文对照；感兴趣再点击“打开原网页”。订阅摘要较短时尝试从公开网页提取正文容器，最多预览 3500 字，作为纯文本呈现，不执行原站脚本。动态页面、登录墙、非 UTF-8 页面或正文提取失败时，显示原因并保留订阅摘要；原站完整内容仍通过外部网页阅读。成功的预览会缓存，翻译或网页读取失败可重试。

所有页面右下角提供“资讯推荐”入口，默认收起；展开后从最近 30 天的启用来源中按来源轮选最多八条，每八秒循环播放，支持上一条、下一条和暂停。鼠标悬停、键盘聚焦、切到后台或打开阅读预览时暂停；系统偏好减少动态效果时默认停播，可手动播放。展开状态和当前条目在本次应用内切换页面时保留，不写入永久设置。推荐沿用中文 / 原文 / 双语，展开时仅按需翻译当前条目。点击标题或“阅读预览”先在工具内阅读，“全部资讯”进入专栏。来源暂停或缓存更新会同步推荐；无近期资讯时明确显示空态。操作通知排列在推荐框上方，弹窗显示在推荐框之上。

网络请求遵循 `HTTPS_PROXY` / `HTTP_PROXY` 等代理环境变量；网络不通时查看来源诊断。工具箱不会自动启用或修改系统代理。浏览器预览只展示页面与桌面能力提示，不伪造资讯。真实采集可运行 `cargo run --manifest-path src-tauri/Cargo.toml --no-default-features --bin inspect-agent-news`，追加 `-- --chinese --custom` 可验证真实翻译、内容预览、自定义 GitHub 订阅及重启持久化；所有结果保存在新建临时目录，不改应用缓存。

## 本地工具使用

从侧栏“工具 → 本地工具”进入，首次自动扫描，之后手动刷新。内置 Node、fnm、uv、Python、Git、pnpm、Bun、Deno、Java、Maven、Rust、rustup、Cargo、mise。检查 PATH、管理器目录与手动添加的目录；Windows 还只读检查注册表 PATH 和安装目录。额外目录不递归遍历。每份安装分别展示路径、版本、来源证据和工具箱当前解析状态。

“添加工具”支持名称及 GitHub 仓库地址。添加仅登记资料，安装须另行预览确认；未知 GitHub 项目没有包映射，不能直接执行安装。资料保存在应用数据目录 `local-tools/tools.sqlite`，联网失败保留旧资料并显示错误。GitHub 最新发布与管理器的可安装版本独立；“可更新”默认提示同一主版本系列内的更新，跨主版本从详情选择。

Windows 使用已安装的 WinGet/Scoop，macOS/Linux 使用已有 Homebrew；Node 使用 fnm，Python 使用 uv，Rust/Cargo 使用 rustup，Java/Bun/Deno/pnpm/Maven 使用 mise。Cargo 安装的 fnm 和独立安装器安装的 uv 按收据识别。工具箱不自动安装管理器或迁移工具；缺少管理器时可查看官方安装与初始化指引。未核实来源的现有工具只提供资料和目录查看，不猜测升级/卸载后端。WinGet 仅凭清单不能证明已有安装来源，工具箱自己的成功安装记录须结合前后文件变化核实。Scoop 全局安装暂不接管；Linux apt/dnf/pacman 不接管。

安装、升级、卸载、默认值和项目修改均先生成后端预览，确认只提交计划 ID。管理器任务串行执行，页面关闭后继续，应用退出后的未完成任务标为中断。日志和操作记录保存在 `local-tools/`，标准输出和错误各限制 1 MiB；成功要求退出码和执行后探测均通过。第三方安装不具备统一回滚事务，失败后重新扫描并报告真实状态。fnm/uv/mise 的版本升级安装所选新版本、保留旧版本，默认值另行设置。

项目固定仅写版本声明，不运行项目任务、hook 或脚本。Node 保留既有 `.node-version`/`.nvmrc`，冲突阻止写入；Python 使用 `.python-version`；Rust 保留旧工具链文件格式；mise 保留已识别配置和无关字段。执行前复核预览内容，在相邻 `.toolbox-backup-*` 文件保存备份。复杂或冲突配置要求人工处理。工具箱当前解析版本、管理器默认值、项目声明分别展示；Rust 额外查询当前进程的实际工具链及环境覆盖。其他项目的实际生效结果标为未核实。不会自动写 PATH、shell 配置，默认值也不会改变已经打开的终端或替换系统 Python。
