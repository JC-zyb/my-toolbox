# Agent Note: Skills 矩阵与批量入口管理

Status: implemented

## Problem

仅中央库列表遗漏全局 Agent 独有技能，已有联接没有工具登记就无法清理。逐技能选择链接类型和 Agent 使统一分发需要反复操作。

## Decision

中央库继续固定为 ~/.agents/skills，矩阵合并中央、各 Agent 与旧库中的同名目录，并保留不同版本的位置。Codex 全局直接可用与 .codex 兼容入口分别呈现。批量预览保存来源、目标指纹及父目录解析结果；执行前统一校验，事务内选择中央版本、导入外部版本、发布入口或移出安装，异常逆序恢复文件并回滚 SQLite。冲突默认跳过，Agent 独有技能先明确选择来源再导入中央。移除外部目录必须通过预览确认，内容变化默认跳过，联接仅移走入口。

与[中央库决策](2026-10-13-skills-library.md)部分重叠：沿用中央目录、导入校验、备份和单技能接口；补充矩阵与已发现外部入口的批量操作，自动链接优先 junction 再 symlink，复制降级需显式允许。旧详情页模式仍作为高级选项保留；批量始终使用自动链接，高级允许复制开关持久化。

矩阵以同名目录为一行，保留所有版本的来源路径和指纹；Codex 全局中央直发现与旧兼容入口分别处理，项目 Codex 则需要安装入口。同名不同版本默认跳过；选择目标版本时先导入中央并备份已有版本，再发布所选入口。同一技能选出多个不同中央版本时拒绝执行。Agent-only 的普通安装接口拒绝隐式导入，页面显式使用 import-and-install；导入项跳过时，其入口安装一并跳过。来源选项按 Windows 规范化路径匹配，但只使用后端预览保存的位置。

整个 Agent skills 目录指向旧库时，普通批量操作禁止穿透父目录联接。迁移预览记录根联接与内容指纹，确认处理全部技能后备份根联接，建立普通目录，并重建 Claude/DSH 单技能入口，清理 Codex 兼容入口；旧库保持原位置。迁移默认保留现有中央版本，相同项重复执行不覆写中央内容。系统保留目录和无法解析的旧库项会暴露诊断，诊断未处理时禁止迁移。

## Alternatives considered

- 整目录共享只需每个 Agent 配置一次，但所有 Agent 被迫拥有同一集合，无法支持所选 Agent 的独立移除。
- 统一复制无需链接权限，但需要维护多份副本及同步，用户选择保留中央单份内容并隐藏链接细节。
- 仅增强单技能详情可以最大限度复用旧界面，但仍需反复逐个操作，也不能直观看到 Agent 独有技能。

## Testing

Rust 33 项测试包括矩阵来源去重/读取失败、中央直发现与项目入口区别、多技能多 Agent 实际 junction 安装、外部联接和目录移除、已修改副本默认跳过、冲突选择目标版本、导入来源歧义、来源/目标变化拒绝、数据库和日志失败回滚、自动链接尝试顺序及错误可见、整目录迁移重复执行和失败恢复。测试均使用系统临时目录。

Playwright 7 项测试连接真实 Rust 核心的隔离目录桥，覆盖迁移默认保留中央、批量链接文件结果、移除后中央保留、Agent 独有导入、冲突默认跳过、过期预览拒绝、外部目录备份删除、键盘选择、浅深色和既有窗口尺寸验收。保留单技能编辑、分发、命令导航等测试。前端单元测试 4 项保持通过。验收命令为 npm run build、npm test、npm run test:rust、npm run test:ui、npm run verify-notes 和 cargo check --manifest-path src-tauri/Cargo.toml。

## Consequences

文件系统与 SQLite 不共享事务，运行时失败逆序回滚；进程突然退出仍需按显示的备份路径人工恢复。保留备份占用磁盘，不自动清理。开发验证仅使用临时目录，不执行真实用户目录迁移或清理。

矩阵按所选工作空间扫描中央、旧库和 Agent 三列，隐藏路径及链接细节；内容指纹需要读取完整支持文件，规模很大的库仍会产生 IO 成本。无需新增依赖。全局 Agent 的实际技能发现行为依赖已批准的本机路径约定，不扩大为对其他版本的兼容承诺。
