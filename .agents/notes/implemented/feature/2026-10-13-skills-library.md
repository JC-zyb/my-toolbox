# Agent Note: Skills 中央库与安全分发

Status: implemented

## Problem

本机与项目的 Agent 技能分散，现有 skills-manager 联接与 .agents 同名内容可能不一致。统一管理需要保留用户目录，辨识来源与同步状态，并可审查迁移影响。

## Decision

本决策的中央路径、导入及单技能接口继续适用。[矩阵与批量入口管理](2026-10-13-skills-matrix.md)补充多 Agent 批量行为，并更新自动链接顺序为 junction → symlink、Codex 兼容目录只清理不重建、已发现外部目录可通过预览备份移除。下文描述原单技能流程的边界；批量和整目录迁移按新笔记执行。

按已批准方案使用 ~/.agents/skills 为中央库，Codex 全局直接发现中央库，.codex/skills 作为兼容发现与迁移目标；Claude Code 与 DSH 使用各自目录。项目只扫描用户登记的路径。与[工作台架构](../architecture/2026-10-12-local-workbench.md)部分重叠，沿用 Rust 阻塞线程、SQLite 与 JSON 配置分工；此笔记补充分发边界。DSH 路径沿用本机约定，不声称已核验所有版本的发现规则。Codex 官方 Skills 页面当前重定向至插件 Skills 文档，未重新确认本地目录，因此 .agents 选择按已批准方案及既有本机配置实施；.codex 兼容路径保留。

目录内容以相对路径与文件字节计算 SHA-256，拒绝导入内部链接与路径逃逸。分发预览由后端保存，执行前重新核对源和目标指纹；外部内容需逐项选择保留中央、保留目标或跳过，并备份后替换。Windows 链接依次尝试 symlink 与 junction，复制降级必须显式授权。失败恢复目标，中央删除采用备份隔离，默认只解除分发。

迁移在 Skills 首次访问时只读预览，确认后备份、校验暂存副本，再发布并重建指向旧库的联接。保留迁移源，重复迁移幂等。Git 使用独立 checkout、结构化参数与受限 HTTPS GitHub URL；导入记录 commit，检查更新只通知，不覆盖。

## Alternatives considered

- 继续 .skills-manager 为主库可以避免迁移和重建联接，但用户已选择 .agents/skills 为统一中央库，旧库作为迁移来源。
- 始终复制免除链接权限差异，但多份副本容易漂移；采用链接优先、显式复制降级并记录同步基线。
- 自动覆盖可缩短操作，但无法区分已有用户目录和本工具管理对象；采用预览指纹、逐项冲突决策和备份。

## Testing

Rust 隔离目录测试覆盖解析、去重、路径边界、外部链接保护、同步模式、冲突、迁移与 Git 失败；SQLite 故障注入验证同步和迁移回滚，junction 清除 reparse point 后须移除空目录壳，才能恢复旧联接。前端测试连接真实 Rust 核心的临时目录桥，覆盖迁移冲突与备份、列表搜索、复制分发实际写入、解除分发、创建、GitHub 输入错误与命令键盘；既有工作台测试保持通过。浅深色及指定尺寸和缩放等效尺寸已检查。验证命令是 build、test、test:rust、test:ui、verify-notes 和 cargo check。

## Consequences

中央库保持单份内容，复制模式有明确同步基线；外部冲突无法无预览覆盖，迁移源与备份保留。文件系统与 SQLite 无法共享事务，运行时异常尝试逆序恢复并显式报告恢复错误；进程在文件发布过程中突然退出仍可能需要从备份人工恢复。备份占用磁盘，后续需要按用户授权清理，当前不自动删除。删除中央内容采用隔离备份，默认仅解除受管理分发；未知外部目录不删除。

网络、认证和 Skill 格式错误可见，Git 操作设 120 秒超时；远程更新只提示 commit 差异，不覆盖本地编辑。私有仓库复用用户 Git 认证，不记录凭据。自动检查只在 Skills 页面打开期间每小时执行。迁移确认只由应用内触发，本次开发操作隔离目录，真实用户库未迁移。Windows 实际 DPI、多屏、安装包与不同 Agent 版本的技能发现仍需人工验收。

真实网络隔离验证从 Anthropic Skills 仓库 main 的 dbd4588f9e1033efb41dad4bef2f7947c8993d44 发现 20 个 Skill，导入 pdf 并检查更新成功。Git 调用局部启用 core.longpaths，避免 Windows checkout 长路径缺文件；不修改用户全局 Git 配置。文件差异用流式 hash 比较，只预览不超过 64 KiB 的文本，不把大支持文件整体装入 UI。
