# Agent Note: Agent 全生态覆盖与中文阅读

Status: implemented

后续入口：[全局推荐轮播](2026-10-18-news-recommendations.md)复用本篇的缓存、语言和预览能力，在其他页面提供右下角阅读入口；不改变采集和翻译契约。

## Problem

用户要求覆盖各类 Agent 而非聚焦 Codex、Claude，且内容优先中文。现有九个固定来源不能覆盖办公、通用、多 Agent 和工作流生态；英文标题与摘要也妨碍日常阅读。

## Decision

保留既有采集、缓存与失败隔离，扩充中文媒体、国内外 Agent 产品、框架、平台、模型及协议来源；按生态领域筛选，支持添加任意公开 HTTPS RSS/Atom 或 GitHub 仓库订阅，避免有限内置名单成为覆盖上限。中文综合科技来源只收录 AI / Agent 相关条目。

默认中文模式，另有原文和双语模式。原生中文直接显示，英文标题与摘要按当前列表阅读需求翻译为简体中文并缓存。Google 公共翻译接口采用结构化批量请求，每批限字数、响应限大小、失败不缓存成功、不自动密集重试；译文与原文内容指纹绑定，更新后不误用旧译文。仅发送公开资讯文本，不发送本机日志、配置、凭据；原文模式关闭新的翻译请求。该公共接口不是有 SLA 的 Cloud Translation，限流或失效必须可见，界面可重试。

复用项目依赖树内的 dom_query 将订阅 HTML 摘要解析为纯文本，避免把 HTML 标签和脚本传给翻译服务。新增翻译缓存表与兼容缺省字段，保留旧缓存和订阅偏好。

点击标题先在工具内预览，再由用户点击“打开原网页”跳转。优先使用订阅正文；订阅仅含短摘要时读取公开网页，以 DOM 正文容器提取最多 3500 字摘录，不执行第三方脚本、不嵌入远程 iframe。预览支持中文和双语，原文可核对；提取或翻译失败显示原因并展示现有订阅文本。成功预览按原文指纹缓存，失败可重试。明确使用“订阅内容 / 网页摘录”标记，避免把有界摘录称为全文。

历史审计：[原资讯模块](2026-10-18-agent-news.md)部分重叠，本篇取代其固定来源上限和不翻译的边界，保留采集与更新规则；工作台、本地工具及 Skills 笔记不涉及新语言契约，沿用其既有模块边界。参考 [translate-tools/core](https://github.com/translate-tools/core/blob/master/src/translators/GoogleTranslator/index.ts) 的公开批量翻译接口和严格响应数量校验，不复制实现。

## Alternatives considered

- 仅添加中文媒体：原生中文质量较好、无额外翻译请求，但媒体无法逐项覆盖所有 Agent 版本发布，因此与官方来源及译文结合。
- 强制配置付费翻译或 LLM Key：有正式服务契约且可优化术语，但用户需要立即可用的中文阅读体验，不能把必需凭据作为默认入口；未来稳定性或质量要求提高时可重访。
- 整库定时翻译：首次进入即可看到全量中文，但大量未读资讯会耗费请求并更易限流；当前阅读列表按需翻译和缓存更合适。
- 远程 iframe 预览：最接近原站交互和排版，但站点 CSP、登录态和第三方脚本会影响可用性及隐私；采用本机提取的纯文本预览，完整内容仍由原网页承载。

## Verification

- 2026-10-18 `inspect-agent-news --chinese --custom` 调用生产服务，在隔离临时目录验证 32 个内置源全部成功、合计 590 条资讯；抽选五条跨来源资讯，四条有真实译文、一条保留原生中文。OpenAI 短摘要实际提取为 3500 字网页摘录，中文译文 1249 字，未返回诊断错误。以上数量仅为该次结果。
- 真实添加 Pydantic AI 仓库订阅，转换为 Atom、读取发布记录、重启保留并移除均通过；不修改用户实际应用缓存。
- Rust 测试验证旧九源缓存与偏好迁移、自定义地址校验和持久化、中文综合源过滤、翻译缓存与内容失效、原文停译、429、异常响应数量和空译文、网页正文提取、预览翻译和缓存、403 / 503 可见且保留原文。
- Playwright 验证领域与中文搜索、失败后重试、中文 / 双语 / 原文、添加重复订阅和移除、先预览后外跳、移动端长文；真实采集和译文数据另外用于桌面 / 手机截图检查，不以受控 IPC 断言替代真实网络。
- 沿用 `npm test`、`npm run test:rust`、`npm run test:ui`、`npm run build:desktop`、`npm run verify-notes` 完成回归、桌面构建和笔记门禁。

## Consequences

广泛内置来源、中文媒体与可扩展订阅共同支持持续覆盖，但无法枚举世界上每个 Agent，界面和交付不得声称穷尽全网。公共翻译可能限流、改变接口或翻译技术术语不准确，保留原文与出处。搜索匹配原文和已缓存译文，不为搜索翻译整库。源数量增加使首次采集耗时增加，继续限制并发和单源超时。预览只读公开文本，正文提取受站点结构、编码、登录和动态渲染限制；失败显式显示并保留订阅内容。
